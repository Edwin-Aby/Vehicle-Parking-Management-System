# Vehicle Parking Management System

A college DBMS micro-project for managing vehicle parking operations.

## Technology Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL (via MySQLi)
- **Environment:** XAMPP (Apache & MySQL)
- **Version Control:** Git / GitHub

## Core Modules
1. **Owner & Vehicle Management** (`modules/owner_vehicle/`)
2. **Parking Slot Management** (`modules/parking_slot/`)
3. **Parking Entry & Exit** (`modules/entry_exit/`)
4. **Billing & Reports** (`modules/billing_reports/`)
